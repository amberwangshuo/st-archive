# 档案 archive

SillyTavern 扩展，配合「档案」主题使用：

- 隔页上的三枚签：index（角色）、records（聊天记录；欢迎页上翻到最近聊天那一叠）、archive（展开顶栏图标；欢迎页上翻回封面）
- 侧面四枚签：style（调色、换图、换字体）、lore（世界书）、preset（AI 设置）、persona（人设）
- 欢迎页的封面：磨砂档案袋里抽出最近聊过的那位
- 底部口袋里的 MEMO 卡：点口袋抽出来；别的插件的按钮和快速回复收在卡片第二行
- 书眉第一张小方图换成当前角色的头像

安装：酒馆 → 扩展 → 安装扩展，贴入本仓库网址。没开档案主题时插件什么都不做。
