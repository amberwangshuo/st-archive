# 档案 archive

SillyTavern 扩展，配合「档案」主题使用（扩展 0.29.0 配套主题 v62 及以上；**使用档案主题时请务必安装并启用本扩展**）：

- **打开酒馆时的交互封面**：壁纸上一只合着的文件夹与相片。等待酒馆初始化的过程中即可直接点击拍立得拿起来、再点翻到背面看日期，或点击后方露出的相片抽出来查看；加载完成后自动翻开进入酒馆（若正在翻看相片，会等你放回后再打开）
- **文件夹上的三枚顶签**：`characters`（角色）、`records`（聊天记录；欢迎页上展开/收起更早的聊天）、`archive`（展开/收起顶栏图标）
- **侧面四枚索引签**：`preset`（AI 设置）、`lore`（世界书）、`persona`（人设）、`style`（样张设置卡）
- **style 样张设置卡**：
  - **配色**：自带四套配色（冷白灰蓝、象牙枯玫瑰、浅灰纯黑、炭黑雾蓝），八项颜色可单独微调；点 `+` 保存自定方案，双击方案名可改名
  - **纸纹**：哑粉纸、书纸、信笺、试卷纸、棉纸、点阵、方格、横线、素白，或自行上传纸纹；每种版式独立记忆纸纹与上传浓淡，每张上传纸纹可通过左上角小锁切换「保持原色 / 随纸色变化」
  - **版式**：图录页、刊物、信、答卷（角色消息为模考语文阅读卷，用户消息为带黑框的语文答题卡）
  - **字体**：中英文字体独立选择，支持贴入外部字体样式链接或直接上传字体文件
- **双击原地修改**：纸面上的标题、题记、来信/回信地址、称呼、开场白、落款、考试名称、收起时的输入栏文案，以及氛围图、封面相片，双击即可原地修改或还原
- **版心反印与字号同步**：书纸与试卷纸的反印墨影限制在阅读区版心内，随正文字号同步缩放，抽屉、弹窗与欢迎页自动回退为干净的哑粉纸
- **全屏阅读**：每张消息纸右上角带全屏记号，点击即可收起文件夹与签，铺满屏幕专注阅读
- **杂志式页码翻页**：最后一张角色消息右下角翻页页码（触屏点击页码开关展开，桌面悬停或点击浮现，`＋` 生成新稿，稿多时点 `…` 打开全部稿）
- **兼容与细节**：适配官方 Chat Top Bar 扩展、酒馆助手 iframe 内嵌卡片正文字体同步、iPhone 添加到主屏幕（PWA）顶部刘海安全区让位，以及输入栏自动收纳第三方扩展按钮与快速回复条

## 安装

酒馆 → 扩展 → 安装扩展，贴入 `https://github.com/sureeyee/st-archive` 安装。未启用「档案」主题时本扩展自动休眠，不改动原界面。

## img/

「档案」主题与「CD·月光」主题使用的纸纹、相片与实物金属件素材存放在 `img/` 下，通过 jsDelivr 按提交号引用，使主题 JSON 保持轻量。
