# 档案 archive

SillyTavern 扩展，配合「档案」主题使用（0.27 配主题 v56）：

- 每张纸右上角一个全屏记号：点了整个聊天界面铺满屏幕（文件夹和签都收起来）
- 纸上的标题、题记、地址、称呼、开场白、落款、卷头、输入框那一句，以及氛围图、封面照片，双击就能原地改，改过的可以还原
- 打开酒馆时的封面：壁纸上一只合着的文件夹。等的时候可以点拍立得拿起来、翻到背面，点后面的相片抽出来看；加载完文件夹自己翻开
- 文件夹上的三枚签：characters（角色）、records（聊天记录；欢迎页上翻到最近聊天那一叠）、archive（展开顶栏图标；欢迎页上翻回封面）
- 侧面四枚签：preset（AI 设置）、lore（世界书）、persona（人设）、style
- style 卡：
  - 配色：四套自带的，八个颜色可以单独调；「+」存下现在的配色，双击名字改名
  - 纸纹：哑粉纸、书纸、信笺、试卷纸、棉纸、点阵、方格、横线、素白，或者上传；每种版式各记各的（默认：图录页哑粉纸、刊物书纸、信信笺、答卷试卷纸）。上传的图裁掉纸边、上下做成无缝的，纸再长也看不出接缝；可以调浓淡
  - 版式：图录页、刊物、信、答卷（角色的每一条是一张模考语文试卷，正文是阅读材料；你的每一条是一张答题卡，上面印着题，正文是作答）
  - 字体：中文、英文各选一种，或者上传字体文件、贴字体链接
- 每张纸上的编号、日期、标题、称呼由插件算好交给主题；头像换成原图
- 刊物和答卷的纸会淡淡地透出背面那一页的字
- 装了官方的 Chat Top Bar 时，那一条排在签下面、纸上面
- 翻页：最后一张纸右下角一排页码（照杂志的页码），点哪个翻到哪一稿；最后一个淡的号码是重新生成；稿很多时中间是「…」，点它打开全部稿
- 手机上侧签压在纸下面只露一条边，点到时浮上来；状态栏那一条取壁纸顶上的颜色
- 垫在消息纸下面的波点纸和蕾丝、从右边夹住整叠纸的夹子
- 从 iPhone 主屏幕图标打开时，顶栏自动让出刘海那一条（别的美化开着时也管）
- 桌面一律是酒馆自己的壁纸，手机顶上那一条也铺成同一张
- 别的插件放在输入栏里的按钮和快速回复，收在输入标签的第二行（点了标签或开始打字时出现）

安装：酒馆 → 扩展 → 安装扩展，贴入本仓库网址。没开档案主题时插件什么都不做。
