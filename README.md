# 档案 archive

SillyTavern 扩展，配合「档案」主题使用（0.12.1 配主题 v31）：

- 打开酒馆时的封面：桌上一只合着的文件夹，点一下进去（style 卡里可以关、可以换照片）
- 文件夹上的三枚签：characters（角色）、records（聊天记录；欢迎页上翻到最近聊天那一叠）、archive（展开顶栏图标；欢迎页上翻回封面）
- 侧面四枚签：preset（AI 设置）、lore（世界书）、persona（人设）、style
- style 卡：
  - 配色：四套自带的，九个颜色可以单独调（包括垫纸和波点），调好的可以起名字存成自己的方案
  - 纸纹：棉纸、书纸、布纹信纸、点阵、方格、横线、素白，或者自己上传一张；三种版式各有默认的纸、各记各的（宽度对齐每张纸、不放大；纸比图长时接上下翻转的同一张，没有接缝；可以调浓淡，花哨的图调淡了不抢正文）
  - 版式：图录页、刊物、信
  - 文字：刊物的标题、信头的地址（角色和你各一行）、信的称呼、开场白和落款（角色和你各一组）、输入框收起时的那一句
  - 图片：底图、封面照片、两张氛围图、输入标签下面晕开的图；底图也可以用酒馆自己的背景
  - 字体：中文和打字机字
- 每张纸上的编号、日期、标题、称呼由插件算好交给主题；头像换成原图
- 翻页：最后一张纸右下角一排页码（照杂志的页码），点哪个翻到哪一稿；最后一个淡的号码是重新生成；稿很多时中间是「…」，点它打开全部稿
- 手机上侧签压在纸下面只露一条边，点到时浮上来；状态栏那一条取壁纸顶上的颜色
- 垫在消息纸下面的波点纸和蕾丝、从右边夹住整叠纸的夹子
- 用酒馆自己的背景时，手机顶上那一条也铺成同一张壁纸
- 别的插件放在输入栏里的按钮和快速回复，收在输入标签的第二行（点了标签或开始打字时出现）

安装：酒馆 → 扩展 → 安装扩展，贴入本仓库网址。没开档案主题时插件什么都不做。
