# 档案 archive

SillyTavern 扩展，配合「档案」主题使用（0.10 配主题 v25）：

- 文件夹上的三枚签：index（角色）、records（聊天记录；欢迎页上翻到最近聊天那一叠）、archive（展开顶栏图标；欢迎页上翻回封面）
- 侧面四枚签：style、lore（世界书）、preset（AI 设置）、persona（人设）
- style 卡：
  - 配色：四套自带的，七个颜色可以单独调，调好的可以起名字存成自己的方案
  - 纸纹：棉纸、点阵、方格、横线、素白，或者自己上传一张（等比例铺满每张纸，不重复平铺）
  - 版式：图录页、刊物、信
  - 文字：刊物的标题、信头的地址行、信的称呼、开场白和落款（角色和你各一组）
  - 图片：底图、封面照片、两张氛围图、输入标签下面晕开的图；底图也可以用酒馆自己的背景
  - 字体：中文和打字机字
- 每张纸上的编号、日期、标题、称呼由插件算好交给主题；头像换成原图
- 垫在消息纸下面的波点纸和蕾丝、从右边夹住整叠纸的夹子
- 用酒馆自己的背景时，手机顶上那一条也铺成同一张壁纸
- 别的插件放在输入栏里的按钮和快速回复，收在输入标签的第二行（点了标签或开始打字时出现）

安装：酒馆 → 扩展 → 安装扩展，贴入本仓库网址。没开档案主题时插件什么都不做。
